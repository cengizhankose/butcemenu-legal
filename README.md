# butcemenu-legal

Public legal and support pages for the Kazan iOS app, served by GitHub Pages (Jekyll):

- https://cengizhankose.github.io/butcemenu-legal/privacy/ (TR)
- https://cengizhankose.github.io/butcemenu-legal/privacy/en/ (EN)
- https://cengizhankose.github.io/butcemenu-legal/terms/
- https://cengizhankose.github.io/butcemenu-legal/support/

Pages whose front matter has `source: docs/legal` are generated from the app repo by
`scripts/release/publish-legal.sh`; edit them there, not here.
